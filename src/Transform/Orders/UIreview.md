REVIEW ON THE UI

The UI is well designed and the colors that match each state works at intended.

GAPS IN THE UI
the escrow and the orders states are yet to be synced with each other (the change in the monetary value does not affect the order status).

I believe some of the order states should be visible only to a specific role e.g the "SENT" state should be visible in the buyer side and not in the maker.

The brief and qoute cards are the same in both roles.
